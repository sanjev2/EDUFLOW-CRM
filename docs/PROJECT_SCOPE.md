# Project Scope

EduFlow is a browser-based application for one education consultancy. It has three planned roles: student, counsellor and administrator. It is not a native application, payment platform, subscription service or multi-tenant product.

## Current stage

This stage establishes the frontend, API, local MongoDB integration, tests and security-oriented documentation. Authentication, MFA, authorisation enforcement and CRM workflows remain unimplemented.

## Exclusions

- Payments and subscriptions
- Multiple consultancies or tenant isolation
- AI, WhatsApp and university APIs
- Deployment
- Formal penetration testing before feature completion
